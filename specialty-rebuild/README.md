# 360客户端：按期刊及关键词专业重建

本版是新增结构CSV，和上一版“按原ID更新的清理版”用途不同。请使用 **360_rebuilt_materials.csv** 新建专业计划及组，旧结构按单独清单处理。

## 导入哪些文件

- 推荐：导入根目录 `360_rebuilt_materials.csv`，包含全部计划、组、关键词和创意。
- 若你的客户端按实体分别导入，可改用 `split/` 下01计划、02组、03关键词、04创意，按顺序导入。**总表与四个分表二选一，不要都导入**，它们内容完全相同。
- `reports/` 和 `delete-old/` 是审计/删除清单，不是新增物料导入文件，勿当物料导入。

全部物料CSV保留原45列、原列顺序，GB18030编码、CRLF换行。新建实体的ID/父ID字段留空，由客户端创建并分配；父子关系通过唯一新计划名、新组名组织。没有把旧关键词ID改挂到新计划/新组，没有复用旧创意ID，也没有伪造新质量度。预算、组出价、关键词出价、业务类目、网址等运行必填均已填好，未混入缺字段草案。

**已完成离线结构、字段与字节校验；尚未在360客户端实测新增导入。**客户端如何识别新建与按名称关联，仍以本机导入结果为准；不能把离线验证称为已在客户端导入成功。若客户端新增不接受总表，可采用分表方式；遇到实际错误需按提示修正，不要先删除旧账户结构。

## 关键词优化

- 继续删除“学科专业+地区+期刊投稿公司”等机械槽位堆叠及明确词序缺陷，不按词长或问句形式一刀切。
- 仅对前序已明确的旧刊名查询改用附件现刊名，保护完整现名，防止“材料科学与工程学报学报”式重复替换；不全局替换旧名子串。
- 更名后若标题通配长度不足，保留完整现刊名并缩短“期刊发表”等查询后缀，不截断正式刊名。
- 规范全半角、中文边界多余空格及独立SCI等索引大小写；不把Science单词内部的SCI字母当索引或改坏英文刊名。
- 同词同匹配跨旧组去重：原27计划的地域范围及控制字段等价，优先保留原有效启用、质量度较高、同等价格较低的来源记录。迁移后的新质量度两列清空。
- 新增词采用明确专业名称+论文投稿/期刊投稿/职称论文投稿/投稿咨询；出价与链接继承同专业真实来源，使用精确匹配。
- 原词出价、PC/移动链接、匹配方式继承所选来源；暂停状态按原有效状态保留，即原词或来源组任一暂停，新词也保持暂停，避免迁移后意外启用旧暂停词。

逐词新旧归属、来源ID、优化动作、出价及链接见 reports/keyword_migration_audit.csv。

## 出价、预算、投放和否定词

原27计划地域只是排序不同，实际31省市集合、设备、时段、比例、日期等控制字段一致；新计划沿用其原值。预算字段原值0原样继承，不把0擅自解释为免费或某个新预算。

所有新计划默认暂停。新组基础出价取该组来源旧组出价的最低值，关键词显式出价保留来源原值。低意向“信息咨询/期刊核验”组默认暂停供单独判断；其余组虽可启用，但仍受新计划暂停状态控制。新增结构不会因导入自动开始消耗。

否定词针对代写、论文买卖等不提供服务和明确免费下载论文需求，保留简洁业务排除，不把旧的跨组路由否定词搬到新结构。已按计划正向词检查，避免新增否定词与保留词直接字面冲突。未编造历史高消耗或转化效果。

## 删除旧结构的顺序

1. 在客户端导入新结构，核对新计划/组/关键词/创意数量和关联、预算及链接；确认新建成功并保留完整备份。
2. 依据 delete-old/old_plans_to_delete.csv 中的27个原计划ID删除旧计划；删除计划可能级联其旧组、关键词和创意。311个旧组的清单用于核对，已随计划删除的组不必再重复删除。
3. 核对新结构完整且旧结构已处理后，再按需要启用新计划及可投放组。

CSV导入本身不会自动删除旧计划。原模板无删除操作列，本版没有伪造“删除”枚举；delete-old中的表也不是可导入删除指令。没有在线登录账户或执行删除、上传、启用操作。

## 验证范围

全部新ID列空且名称关联唯一；运行必填完整；每组均有真实关键词与3条创意。标题≤45字节、两描述各≤70，额外采用动态含括号≤45及双描述拼接≤70的保守规则。新创意不含未经证实的3~7天审稿、次月见刊等承诺。

四个分表与总表逐行内容相同；逐词来源价格、链接、匹配、有效暂停状态及旧ID删除清单均有独立复核记录。当前出版状态、所有落地页内容和客户端实际导入结果仍不属于已完成的离线验证范围，不宣称已获取全部知网符合条件期刊。
