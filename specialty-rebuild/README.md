# 专业分类物料：每组9条原创意有限调整版

本版包含15个计划、2,269个推广组、158,707个关键词和20,421条创意。计划和组按期刊、关键词专业类别划分；计划、组、关键词与已完成的专业重建版逐字段一致。本次只为新组配置原创意，替换此前助手生成的创意版本。

## 下载与导入

完整物料使用本目录 `360_rebuilt_materials.csv`；Git仓库根目录 `360_Original_Creatives_9_Per_Group_20261027.csv` 是同字节副本。CSV保留原始45列、GB18030无BOM编码和CRLF换行。

如果客户端按实体分别导入，可按 `split/01_new_plans.csv`、`02_new_groups.csv`、`03_new_keywords.csv`、`04_new_creatives.csv` 顺序操作。总表与分表二选一，避免重复导入。`reports` 中的核对资料不能作为物料导入。

新实体各类ID均留空，以唯一计划名和组名关联，由客户端分配ID。所有新计划默认暂停；原预算、地域等设置保留，关键词出价、匹配、链接及原有效暂停状态保持。已完成离线结构检查，尚未在360客户端实际导入，也未向线上账户写入。

## 原创意使用范围

创意来自最初上传CSV中的19个来源ID，每条的标题、描述1、描述2均来自同一源记录，原状态和四个网址字段一起沿用。仅替换原本已有的 `{通配词}`；仅在替换后字段实际超长时，删除原有整句、片段和多余分隔符进行精简。不增写、不换字或重排，未超长字段除通配内容外保持原文。未使用之前助手重写的创意。

每组最终三字段组合恰好9条且互不重复；去除标点、空格并统一英文大小写后仍有9条。采用本组最长实际关键词作为通配默认词，并逐个组词核对动态替换字节。标题不超过45字节，两段描述分别不超过70字节，按严格GBK计数，检查时保守保留花括号。

逐条来源和改动见 `reports/creative_original_reuse_trace.csv`、`creative_limited_edit_audit.csv`。逐组数量见 `nine_creatives_per_group.csv`，独立核验摘要见 `independent_limited_edit_validation.json` 和 `delivery_contract_validation.json`。
