# 360点睛客户端CSV清理版

## 使用哪个文件

**360_clean_materials.csv 是客户端物料文件**。原45列、原列顺序、GB18030编码、CRLF换行；文件不是Excel或审计表。全部为现有物料ID，无空ID、无缺预算/出价/链接的新建草案。按与原全账户CSV相同的客户端导入方式导入并按原ID更新。

其余CSV均为删除清单或校验说明，不是物料文件，请勿当物料导入。

## 已直接删除的内容

原196,524条关键词，已从主CSV直接移除17,543条，保留178,981条。没有暂停版，也没有把待删词以暂停状态塞回主CSV。

|删除类别|唯一关键词行数|
|---|---:|
|畸形或机械模板词|16,665|
|同组同匹配规范化重复|249|
|附件中明确停刊/合并或非指定出版周期的期刊查询|608|
|代写、买论文等敏感需求或结果保证词|21|

畸形规则包含：重复“投稿投稿/发表发表”、非比较语境下重复“核心期刊”、非医学专业硬接“医学论文”、完整模板中的专业/职业/索引错配，以及“学科专业+地区+论文发表公司/SCI代发公司”等多槽位堆砌。后几类是本次账户清理策略，不表示这些词绝无搜索价值；没有用搜索量或成效数据证明收益。自然长尾、正常问句和口语不因词长删除。

重复只在同组同匹配内按NFKC去空白、忽略大小写归并，优先保留启用且质量度较高的原ID；未自动删除跨地域/跨组路由词。

期刊排除依据是用户提供的知网摘录；未重新在线核验全部期刊。短泛词及分版不清的查询不自动归为具体期刊，避免误删。此版为现有账户清理，不冒充全知网期刊补全版。

## 原账户里的旧词如何处理

**从CSV删除行，不等于已从线上账户删除。**原45列模板没有删除操作列，本次没有捏造“删除”枚举。已有账户旧词请依据 `deleted_keyword_ids.csv` 中的原关键词ID，在客户端执行批量删除；普通导入主CSV不会自动删除账户里缺失的旧词。这份清单不是删除指令导入模板，不应作为普通物料导入。

## 保留和更新的范围

主CSV包括27计划、133个有词组、178,981条关键词及3,225条已重写创意。全部保留词的文字、ID、匹配、出价、链接、状态不变；原计划预算、地域、设备、时段等控制字段不变；90个否定词字段沿用前一轮已记录的优化。所有重写创意的默认词来自清理后本组真实保留词，未用被删除的词作通配符。

178个未导出关键词的组及其4,475条创意未放入此次主CSV，原因是无法验证真实通配词。省略不表示线上已删除；详见 `excluded_empty_groups.csv`。原始输入及上一版ZIP保留，可追溯。

## 已完成的检查

- 原45列和行宽、GB18030严格解码、CRLF、ID及父子名称关联通过。
- 保留行的原控制字段和链接保护检查通过。
- 3,225条创意和3,937,598次实际逐词动态替换检查通过：标题≤45字节，双描述分别≤70，动态含括号保守值≤45；两描述拼接也≤70。
- 删除清单与主文件移除的关键词ID逐项对应。校验结果文件记录范围。

已完成离线结构和字段校验，**尚未在360客户端实际试导入**；平台实际审核与客户端版本兼容性不能冒称已验证。请在客户端查看导入差异，确认是按现有ID更新后提交。没有对线上账户执行任何删除、上传或投放操作。
